From Ticks to Memory

How a circuit keeps time, and how keeping time lets it remember.

Scroll

1. Keeping time

A bucket and a narrow pipe

A capacitor stores electric charge. Picture a bucket.

A resistor slows down current, which is charge on the move. Picture a narrow pipe.

Close the switch. The battery pushes charge through the pipe into the bucket.

It fills fast at first, then slower as it gets full. Filling takes time. That delay is how a circuit measures time.

The screen works like a heart monitor. Higher means more voltage, the electric push. Further right means later.

1. Keeping time

The 555 timer repeats it

The 555 is a cheap and famous chip. A chip is a tiny package of circuits.

It watches how full the bucket is.

At 2/3 full, it opens a drain. At 1/3 full, it closes the drain, so the bucket fills again.

Fill, drain, fill, drain. Now the circuit has a steady beat.

2. Making a clock

Keep only the flips

The chip has an output pin. That is a metal leg that sends a signal out.

It is on while the bucket fills. It is off while the bucket drains.

On, off, on, off. This shape is a square wave. Engineers call it a clock.

High means 1. Low means 0.

Each jump from low to high is a tick. Every tick says: now.

3. Remembering

Memory means holding a state

A doorbell rings only while you press it. Let go and it stops. It forgets.

A light switch stays where you left it. It remembers.

A latch is the light switch kind. It is built from two logic gates. A gate is a tiny decision maker.

Each gate feeds its answer into the other. That loop holds itself in place. Press SET and the output, called Q, turns on. Let go and Q stays on.

3. Remembering

The clock says when to listen

A D flip-flop is a latch with a clock input. D is the data coming in.

Most of the time it ignores D.

On each tick it copies D to Q. Then it holds that value until the next tick.

The rows on the screen show it. Q only changes on a tick.

3. Remembering

That is one bit

A bit is a single 0 or 1.

A flip-flop holds one bit for as long as it has power.

A processor, the chip that runs a computer, keeps the numbers it is working on in rows of flip-flops like this. On every tick of its clock, they can all update together.

Recap

From ticks to memory

  1. A capacitor filling through a resistor takes a set amount of time.
  2. A 555 chip fills and drains it over and over. Its output is a clock.
  3. A latch feeds its output back into itself, so it holds a 0 or a 1. A clock decides when it may change.
